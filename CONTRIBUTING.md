# Contributing to Jarvis-AI

Thanks for helping improve this experimental project.

1. Check existing issues and open a focused issue for a reproducible bug or a proposed feature.
2. Fork the repository and create a descriptive branch.
3. Keep pull requests small; describe the platform (Android, Windows, or Vision), the change, and how you tested it.
4. Never commit API keys, passwords, personal data, generated build outputs, or machine-specific paths.
5. For Android changes, explain Flutter/Android versions, dependencies, permissions and any device testing. The checked-in standalone Dart file is not a complete Flutter app.
6. For Windows changes, list Python version and any additional dependencies you introduce.

Please use English for issue titles when possible; other languages are welcome if accompanied by a brief English summary. Be respectful and avoid posting unrelated AI-generated content.
