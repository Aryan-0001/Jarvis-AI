Getting started

Android: bring your own Gemini API key

Want to experiment with the Android source? Here's exactly where the current code expects your key and model name.

  1. Get your own key from Google AI Studio. Never share or commit it.
  2. Open JarvisAppFlutter/jarvis.dart and find class _JarvisScreenState.
  3. Find final String apiKey = "get your api";. Replace the placeholder only in your private local copy, or use the compile-time configuration method explained in the guide.
  4. In initState(), replace the put-exact-model-name-here placeholder with an available Gemini model ID supported by your SDK and account.
  5. Follow the full Android setup guide to create a Flutter scaffold, install dependencies, configure permissions and assets, and run locally.

Security: A key embedded in an Android APK can be extracted, even when passed using --dart-define. Use restricted, quota-limited keys for personal experiments; a public app should keep its provider key behind a secure backend.

Before you install

Frequently asked questions

Can I download a working Android APK today?

The published APK is under maintenance. You can browse GitHub releases, but compatibility and functionality are not guaranteed. No release date is confirmed.

Does the Android code work immediately after cloning?

No. The checked-in jarvis.dart is standalone source. It needs a complete Flutter project, compatible packages, permissions and assets. Read the Android guide first.

Do I need to provide my own API key?

For Gemini-powered Android responses, yes. The repository contains placeholders rather than a usable key and model name. Keep your own key private and understand the risks of embedding it in a client app.

How do I report a problem or contribute?

Read the contribution guide and open a GitHub issue with the platform, steps to reproduce and sanitized error messages.
